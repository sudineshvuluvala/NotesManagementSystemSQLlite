About Notes App

Notes App is a simple web application for saving, reviewing, editing, and organizing personal notes in one place.

Private workspace

Each account can access only its own notes.

Easy note management

Create, search, view, update, and delete notes.

Secure passwords

Passwords are stored as one-way hashes, not plain text.

Built for learning

Uses Python, Flask, MySQL, HTML, CSS, and Bootstrap 5.
